## 项目结构

```
https-smb-server/
├── main.py                    # 主入口
├── requirements.txt           # Python 依赖
├── README.md                  # 项目说明
├── core/
│   ├── __init__.py
│   ├── config.py              # 配置管理
│   └── filesystem.py          # 文件系统操作核心
├── server/
│   ├── __init__.py
│   └── routes/
│       ├── __init__.py
│       ├── files.py           # 文件操作路由
│       ├── upload.py          # 上传路由
│       └── download.py        # 下载路由
├── static/
│   └── index.html             # 前端界面
└── data/                      # 文件存储目录（运行时自动创建）
```
