## 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `HTTPS_SMB_ROOT` | 存储根目录 | `./data` |
| `HTTPS_SMB_HOST` | 监听地址 | `0.0.0.0` |
| `HTTPS_SMB_PORT` | 监听端口 | `8080` |
| `HTTPS_SMB_CHUNK_SIZE` | 分块上传大小（字节） | `8388608` (8MB) |
| `HTTPS_SMB_DOWNLOAD_CHUNK` | 下载流式块大小（字节） | `4194304` (4MB) |
